# weather-forecast
The project weather forecast application uses JavaScript, HTML, and CSS. Which retrieves data from OpenWeatherMap API and location-based forecasts, current weather conditions, and extended forecasts. 

Tools and Technologies used
- HTML 
- TailwindCss
- JavaScript 

API keys
- API keys is used from Open Weather API (which is free)

Features of this project
- can get weather report for the desired city 
- can get weather report Using Current Location 
- can toggle betweem light and dark mode 
- can get weather report for current day and for the next 5 days 
- can use across multiple devices
